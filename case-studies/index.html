導入事例

数値で検証できた成果のみを掲載しています。守秘義務の都合により社名は伏せていますが、詳細は個別のご相談時にご説明可能です。

SaaS企業 — AIカスタマーサポート構築

成果: 問い合わせの自動応答率 92%

  • 課題 — 問い合わせの約80%がFAQで回答可能な内容だったが、サポート担当がすべて一次対応しており、複雑な案件に時間を割けていなかった
  • アプローチ — ヘルプセンターと過去の問い合わせ履歴をRAGの検索対象とし、回答不能と判断した場合は有人にエスカレーションするエージェントを構築。自信度の閾値を運用しながら調整
  • 技術 — Amazon Bedrock / OpenSearch / Lambda / Step Functions
  • 期間 — PoC 6週間、本番開発 4か月

製造業 — 品質レポート自動生成

成果: レポート作成工数 90%削減

  • 課題 — 検査データからの日報作成に、担当者1名あたり1日2時間を要していた
  • アプローチ — 検査システムのデータを取得し、テンプレートに沿ったレポートをLLMで生成。異常値の検知時のみ担当者にレビューを求めるワークフローに変更
  • 技術 — Vertex AI / Gemini / Cloud Functions / BigQuery
  • 期間 — PoC 4週間、本番開発 3か月

金融機関 — 社内ナレッジ検索システム

成果: 回答までの時間 75%短縮

  • 課題 — 規程・通達・マニュアルが複数システムに分散し、正確な情報の特定に時間がかかっていた
  • アプローチ — 多段階RAG（検索 → 再ランキング → 回答生成）を構成し、回答に必ず根拠文書へのリンクを付与。部署ごとのアクセス権限を検索インデックスの段階で分離
  • 技術 — Amazon Bedrock / OpenSearch / Step Functions
  • 期間 — PoC 8週間、本番開発 6か月

EC企業 — 商品説明の生成パイプライン

成果: 商品登録スループット 6倍

  • 課題 — 新商品登録時の説明文作成が属人化し、登録の待ち行列が慢性化していた
  • アプローチ — 商品画像とスペック表から説明文を生成し、担当者のレビュー画面に流し込むパイプラインを構築。ブランドトーンの逸脱は事前チェックで弾く構成
  • 技術 — Vertex AI / Gemini / Cloud Run / Pub/Sub
  • 期間 — PoC 5週間、本番開発 3か月

物流企業 — 配車計画の意思決定支援

成果: 計画作成時間 60%短縮

  • 課題 — 配車計画の作成が特定担当者の経験に依存し、属人化のリスクが高かった
  • アプローチ — 既存の最適化エンジンの出力をLLMが自然言語で説明し、担当者が制約条件を対話的に修正できるインターフェースを構築
  • 技術 — Amazon Bedrock / ECS / PostgreSQL
  • 期間 — PoC 6週間、本番開発 4か月
